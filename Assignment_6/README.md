## 🚀 How to Run

1. **Google Colab (Recommended):**
* Open Assignment_6.ipynb on GitHub and click the **Open in Colab** badge (or upload the notebook directly to Google Colab).
* Ensure the runtime environment has GPU acceleration enabled (`Runtime` > `Change runtime type` > `Hardware accelerator` > `GPU`).
* Run all cells sequentially.


2. **Local Environment:**
* Clone the repository:
```bash
git clone [https://github.com/Vaibhav5719v/DL_Assignments.git](https://github.com/Vaibhav5719v/DL_Assignments.git)
cd DL_Assignments/Assignment_6

```


* Install required dependencies:
```bash
pip install -r requirements.txt  # or install torch, numpy, matplotlib, etc.

```


* Launch Jupyter Lab or Notebook:
```bash
jupyter notebook Assignment_6.ipynb

```
