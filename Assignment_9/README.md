## 🚀 Getting Started

### Prerequisites

Ensure you have Python 3.8+ installed along with the required libraries:

```bash
pip install torch torchvision numpy pandas matplotlib scikit-learn

```

*(Adjust packages according to your specific deep learning framework like TensorFlow/PyTorch)*

### Running the Notebook

1. Clone the repository:
```bash
git clone [https://github.com/Vaibhav5719v/DL_Assignments.git](https://github.com/Vaibhav5719v/DL_Assignments.git)

```


2. Navigate to the Assignment 9 directory:
```bash
cd DL_Assignments/Assignment_9

```


3. Launch Jupyter Notebook or JupyterLab:
```bash
jupyter notebook Assignment_9.ipynb

```
